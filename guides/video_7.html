{% if lang == 'en' %}Step-by-Step Guide{% else %}步驟說明{% endif %}

  1. {% if lang == 'en' %}Go to Caverns of Time{% else %}前往時光之穴{% endif %}
    {% if lang == 'en' %}Travel to the Caverns of Time in Tanaris.{% else %}前往塔納利斯的時光之穴。{% endif %}
  2. {% if lang == 'en' %}Find Chromie and Get the Bloody Broom{% else %}找到克羅米獲取染血的掃帚{% endif %}
    {% if lang == 'en' %}Inside the Caverns, find Chromie. Look for scattered parts on the ground and click them to receive the Bloody Broom.{% else %}進入時光之穴後，找到 克羅米。點擊地上的散落零件來獲得 染血的掃帚。{% endif %}
  3. {% if lang == 'en' %}Use the Broom to Track Parts{% else %}使用掃帚追蹤零件{% endif %}
    {% if lang == 'en' %}Equip or hold the Bloody Broom. Yellow dots will appear on your minimap indicating nearby collectible parts.{% else %}裝備或持有 染血的掃帚，小地圖上會顯示黃點來指示附近可收集的零件。{% endif %}
  4. {% if lang == 'en' %}Collect All 5 Parts{% else %}收集全部 5 個零件{% endif %}
    {% if lang == 'en' %}Parts may be found in areas such as: Goldshire (Elwynn Forest), Razor Hill (Durotar), Crossroads (The Barrens), Dalaran (Broken Isles), Stormwind or Orgrimmar.{% else %}零件可能出現在以下區域：閃金鎮（艾爾文森林）、剃刀嶺（杜隆塔爾）、十字路口（貧瘠之地）、達拉然（破碎群島）、暴風城或奧格瑪。{% endif %}
  5. {% if lang == 'en' %}Return to Chromie and Assemble Patch{% else %}回到克羅米處組裝帕奇{% endif %}
    {% if lang == 'en' %}After collecting all 5 parts, return to the Caverns of Time and speak with Chromie. Complete the assembly and you will receive the achievement "Patches the Player". Patch the pet will be mailed to you!{% else %}收集完 5 個零件後，回到 時光之穴 與克羅米對話。完成組裝後會獲得成就 「全能帕奇！」，寵物帕奇會寄到你的信箱！{% endif %}

{% if lang == 'en' %}Returning in Patch 12.07{% else %}12.07 版本回歸獲取方式{% endif %}

  1. {% if lang == 'en' %}Find the Starting NPC{% else %}找到起始 NPC{% endif %}
    {% if lang == 'en' %}Travel to Frostfire Ridge (Warlords of Draenor) and locate the non-interactive NPC Marrow.{% else %}前往 霜火峰（德拉諾之霸），找到無法直接互動的 NPC 莫羅斯。{% endif %}
  2. {% if lang == 'en' %}Purchase the Detection Item{% else %}購買偵測道具{% endif %}
    {% if lang == 'en' %}Go to Vol'dun (Battle for Azeroth) and buy a special item from Lok'rath that allows you to see invisible demonic runes.{% else %}前往 沃魯敦（決戰艾澤拉斯），從 洛克拉斯 處購買可以看見隱形惡魔符文的神秘道具。{% endif %}
  3. {% if lang == 'en' %}Find the Hidden Runes{% else %}尋找隱藏符文{% endif %}
    {% if lang == 'en' %}Use the item in Darkshore (Cataclysm version) to reveal invisible demonic runes. Follow the rune trail.{% else %}在 黑海岸（浩劫與重生版本）使用道具，來發現隱形的惡魔符文，並沿著符文線索前進。{% endif %}
  4. {% if lang == 'en' %}Travel to Blasted Lands{% else %}前往詛咒之地{% endif %}
    {% if lang == 'en' %}Go to the Cataclysm version of Blasted Lands and find the invisible Baa'l NPC. Defeat it to unlock the ability to purchase the pet.{% else %}前往 浩劫與重生版本的詛咒之地，找到隱形的 Baa'l NPC 並擊敗它，解鎖購買寵物的資格。{% endif %}
  5. {% if lang == 'en' %}Obtain Baa'l{% else %}獲得小歪比哇嗚{% endif %}
    {% if lang == 'en' %}After defeating the invisible Baa'l, you can now purchase the Baa'l battle pet.{% else %}擊敗隱形的 Baa'l 後，即可購買 小歪比哇嗚 戰鬥寵物。{% endif %}
