  2. {% if lang == 'en' %}Translation Gear (Recommended){% else %}翻譯裝備（建議）{% endif %}

  3. {% if lang == 'en' %}Check Weekly Rotation{% else %}確認週常輪換{% endif %}

{% if lang == 'en' %}Step 1 — Find the Waterlogged Note{% else %}步驟一 — 尋找浸水的筆記{% endif %}

  1. {% if lang == 'en' %}Search the Northwest Coast{% else %}搜尋西北方海岸{% endif %}
    {% if lang == 'en' %}Head to the northwest coastline of Isle of Dorn. Look for shipwrecks or underwater areas near the shore.{% else %}前往多恩島西北方海岸線。在近海的沉船或水下區域尋找。{% endif %}
  2. {% if lang == 'en' %}Locate the Waterlogged Note{% else %}找到浸水的筆記{% endif %}
    {% if lang == 'en' %}Find the Waterlogged Note item. It may spawn in multiple locations near the water — check wreckage debris thoroughly.{% else %}找到 「浸水的筆記」 物品。它可能在水邊多個位置刷新 — 仔細檢查沉船殘骸。{% endif %}
  3. {% if lang == 'en' %}Read the Note{% else %}閱讀筆記{% endif %}
    {% if lang == 'en' %}Right-click the note to read it. If the text appears as gibberish, equip your translation gear and try again — the hidden message will be revealed.{% else %}右鍵點擊筆記閱讀。如果文字顯示為亂碼，裝備翻譯道具後再試 — 隱藏訊息將會顯現。{% endif %}
{% if lang == 'en' %}Tip:{% else %}提示：{% endif %} {% if lang == 'en' %}If the Waterlogged Note is not visible, try switching shards or relogging. Some players report the note may be phased.{% else %}若浸水的筆記沒有出現，嘗試切換位面或重新登入。部分玩家反映該筆記可能存在鏡像問題。{% endif %}

  1. {% if lang == 'en' %}Collect Scattered Notes{% else %}收集散落的筆記{% endif %}

  2. {% if lang == 'en' %}Decode Morse Code / Symbols{% else %}解讀摩斯密碼 / 符號{% endif %}

  3. {% if lang == 'en' %}Look for "Deep" and "Cat" References{% else %}尋找「深處」與「貓」的提示{% endif %}
    {% if lang == 'en' %}The puzzle themes revolve around "Deep" and "Cat" — expect to head toward underwater caves or deep underground areas on the island.{% else %}謎題主題圍繞「深處」與「貓」— 預期需要前往島上的水下洞穴或深層區域。{% endif %}

  1. {% if lang == 'en' %}Navigate the Underwater Cave{% else %}進入水下洞穴{% endif %}

  2. {% if lang == 'en' %}Find the Hidden Chest{% else %}尋找隱藏寶箱{% endif %}
