{% if lang == 'en' %}Overview{% else %}概述{% endif %}

{% if lang == 'en' %}

The Tormented Devourer is a mount obtained by completing the “Heroic: Battle for the Void” achievement in Patch 12.07. This achievement consists of 6 sub-achievements spread across the Val and Nalgathar zones. Once all 6 are completed, exchange 15 Void Radiance to claim the mount.

{% else %}

受折磨的饕餮者是一款坐騎，透過完成 12.07 版本的「英雄虛空決戰」成就獲取。該成就由 6 個子成就組成，分佈在瓦爾和奈格塔爾兩個區域。完成全部 6 個子成就後，用 15 個虛光輝顏兌換坐騎。

{% endif %}

{% if lang == 'en' %}Key Tips{% else %}核心攻略{% endif %}

{% if lang == 'en' %}1. Maximize Efficiency by Stacking Achievements{% else %}1. 善用子成就重疊進度{% endif %}

{% if lang == 'en' %}

Several sub-achievements can be progressed simultaneously. While doing world quests in Val and Nalgathar, you will naturally encounter rare mobs and buff-carrying enemies. Prioritize quests that overlap with rare spawn or energy mob zones for maximum efficiency.

{% else %}

多個子成就可同步推進。在瓦爾和奈格塔爾做世界任務的同時，你自然會遇到稀有怪和攜帶 buff 的小怪。優先選擇與稀有怪或能量怪區域重疊的任務以最大化效率。

{% endif %}

{% if lang == 'en' %}2. Weather Anomaly Quests Are Time-Gated{% else %}2. 氣象異變任務有時限{% endif %}

{% if lang == 'en' %}

The weather anomaly quests (Storm Response in Val and Spore Storm in Nalgathar) each require 5 completions. These spawn on a rotating schedule. Check both zones regularly and prioritize these whenever they appear.

{% else %}

氣象異變任務（瓦爾的風暴對策和奈格塔爾的孢子風暴）各需完成 5 次。它們會按照輪換排程出現。定期檢查兩個區域，一旦出現就優先完成。

{% endif %}

{% if lang == 'en' %}3. Bosses: Node Captain Layshel & Imperator Hotinax{% else %}3. 首領戰：節點隊長萊希爾 & 元首霍提納克斯{% endif %}

{% if lang == 'en' %}

Heroic: Fall of Commanders requires defeating both bosses. These are zone-level elites. Form a group or look for pickup groups in the Group Finder to make this significantly easier.

{% else %}

「英雄：統帥之殤」需要擊敗兩位首領。它們是區域級菁英。建議組隊或透過預組隊伍尋找器找隊友，大幅降低難度。

{% endif %}

{% if lang == 'en' %}4. Rare Mobs: Use RareScanner{% else %}4. 稀有怪：使用 RareScanner 插件{% endif %}

{% if lang == 'en' %}

Heroic Heavy Hitter requires defeating 15 rare mobs. Install RareScanner addon for audible alerts whenever a rare mob spawns nearby. Combine this with world quest farming for natural progress.

{% else %}

「英雄重擊」需擊殺 15 隻稀有怪。安裝 RareScanner 插件可在稀有怪出現時發出音效提示。搭配世界任務刷取可自然推進進度。

{% endif %}

{% if lang == 'en' %}5. Collect 15 Void Radiance to Exchange{% else %}5. 收集 15 虛光輝顏兌換坐騎{% endif %}

{% if lang == 'en' %}

After completing all 6 sub-achievements, you still need 15 Void Radiance to purchase the mount from the reward vendor. These are obtained throughout the achievement process. Make sure you have enough before heading to the vendor.

{% else %}

完成全部 6 個子成就後，還需 15 個虛光輝顏向獎勵商人購買坐騎。虛光輝顏在完成成就過程中逐步獲取。出發兌換前確認數量足夠。

{% endif %}
