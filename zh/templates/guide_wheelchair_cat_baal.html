🐾 {% if lang == 'en' %}Pet #1 — Patch (Wheelchair Cat){% else %}寵物 #1 — 輪椅喵（帕奇）{% endif %}

{% if lang == 'en' %} A white cat in a wheelchair, a loving tribute to the classic Hearthstone character "Patches". This pet is obtained through the Hearthstone Anniversary hidden puzzle quest, earning you the achievement "Patches the Player" (全能帕奇！). {% else %} 一隻坐著輪椅的白色貓咪，溫馨致敬《爐石戰記》經典角色「帕奇」。通過爐石週年慶隱藏解密任務獲得，解鎖成就 「全能帕奇！」。 {% endif %}

{% if lang == 'en' %}How to Obtain{% else %}獲取方式{% endif %}

  1. {% if lang == 'en' %}Travel to Caverns of Time{% else %}前往時光之穴{% endif %}
    {% if lang == 'en' %}Go to the Caverns of Time in Tanaris and find Chromie.{% else %}前往塔納利斯的時光之穴，找到 克羅米。{% endif %}
  2. {% if lang == 'en' %}Obtain the Bloody Broom{% else %}獲取染血的掃帚{% endif %}
    {% if lang == 'en' %}Look for scattered parts on the ground near Chromie and click them. You will receive the Bloody Broom (染血的掃帚).{% else %}在克羅米附近尋找散落的零件並點擊，獲得 染血的掃帚。{% endif %}
  3. {% if lang == 'en' %}Track Parts with the Broom{% else %}使用掃帚追蹤零件{% endif %}
    {% if lang == 'en' %}Equip or hold the Bloody Broom — yellow dots will appear on your minimap indicating nearby collectible parts.{% else %}裝備或持有染血的掃帚，小地圖上會顯示黃點，指示附近可收集的零件位置。{% endif %}
  4. {% if lang == 'en' %}Collect All 5 Parts{% else %}收集全部 5 個零件{% endif %}
    {% if lang == 'en' %}The 5 parts are scattered across Azeroth. Common locations include:{% else %}5 個零件散布在艾澤拉斯各處，常見位置包括：{% endif %}
    • {% if lang == 'en' %}Goldshire, Elwynn Forest{% else %}閃金鎮，艾爾文森林{% endif %}
    • {% if lang == 'en' %}Razor Hill, Durotar{% else %}剃刀嶺，杜隆塔爾{% endif %}
    • {% if lang == 'en' %}Crossroads, The Barrens{% else %}十字路口，貧瘠之地{% endif %}
    • {% if lang == 'en' %}Dalaran, Broken Isles{% else %}達拉然，破碎群島{% endif %}
    • {% if lang == 'en' %}Stormwind City / Orgrimmar{% else %}暴風城 / 奧格瑪{% endif %}
  5. {% if lang == 'en' %}Assemble Patch and Claim Your Pet{% else %}組裝帕奇並領取寵物{% endif %}
    {% if lang == 'en' %}Return to Chromie at the Caverns of Time. Complete the assembly quest and earn the achievement "Patches the Player". Patch will be mailed to you!{% else %}回到時光之穴找克羅米，完成組裝任務後獲得成就 「全能帕奇！」，帕奇會寄到你的信箱！{% endif %}

🐐 {% if lang == 'en' %}Pet #2 — Baa'l (Little Baa'l Wawu){% else %}寵物 #2 — 小歪比哇嗚 (Baa'l){% endif %}

{% if lang == 'en' %} Baa'l is a secret demonic goat battle pet that first appeared in Battle for Azeroth. After a 5-year wait, Baa'l returns in Patch 12.07 with a new way to obtain this elusive companion. Originally one of the most complex secret hunts in WoW history, the 12.07 version streamlines some steps while preserving the mystery. {% else %} 小歪比哇嗚 (Baa'l) 是一隻隱藏的惡魔山羊戰鬥寵物，最早在《決戰艾澤拉斯》亮相。經過 5 年的等待，Baa'l 在 12.07 版本回歸，並提供新的獲取途徑。原本是魔獸史上最複雜的隱藏任務之一，12.07 版本簡化了部分步驟，同時保留了神秘感。 {% endif %}

{% if lang == 'en' %}How to Obtain (12.07 Version){% else %}獲取方式（12.07 版本）{% endif %}

  1. {% if lang == 'en' %}Step 1: Frostfire Ridge — Find Marrow{% else %}步驟 1：霜火峰 — 尋找莫羅斯{% endif %}
    {% if lang == 'en' %}Travel to Frostfire Ridge (Warlords of Draenor) and locate the non-interactive NPC Marrow near Thunderlord Stronghold.{% else %}前往霜火峰（德拉諾之霸），在雷霆王氏族要塞附近找到無法直接互動的 NPC 莫羅斯。{% endif %}
  2. {% if lang == 'en' %}Step 2: Vol'dun — Buy the Rune Detector{% else %}步驟 2：沃魯敦 — 購買符文偵測器{% endif %}
    {% if lang == 'en' %}Travel to Vol'dun (Battle for Azeroth) and find Lok'rath. Purchase a special item that reveals invisible demonic runes.{% else %}前往沃魯敦（決戰艾澤拉斯），尋找 洛克拉斯 並購買可看見隱形惡魔符文的特殊道具。{% endif %}
  3. {% if lang == 'en' %}Step 3: Darkshore — Follow the Rune Trail{% else %}步驟 3：黑海岸 — 追蹤符文線索{% endif %}
    {% if lang == 'en' %}Go to Darkshore (Cataclysm version). Use the item to reveal invisible demonic runes. Follow the trail they reveal.{% else %}前往黑海岸（浩劫與重生版本），使用道具顯示隱形的惡魔符文，並沿著符文所示的線索前進。{% endif %}
  4. {% if lang == 'en' %}Step 4: Blasted Lands — Defeat Baa'l{% else %}步驟 4：詛咒之地 — 擊敗 Baa'l{% endif %}
    {% if lang == 'en' %}Travel to the Cataclysm version of Blasted Lands. Find and defeat the invisible Baa'l NPC to unlock the pet purchase.{% else %}前往浩劫與重生版本的詛咒之地，找到並擊敗隱形的 Baa'l NPC 以解鎖寵物購買資格。{% endif %}
  5. {% if lang == 'en' %}Step 5: Purchase Baa'l{% else %}步驟 5：購買小歪比哇嗚{% endif %}
    {% if lang == 'en' %}After defeating Baa'l, interact with the "Forgotten Offering" on the ground to obtain the Baa'l battle pet!{% else %}擊敗 Baa'l 後，與地上的「被遺忘的祭品」互動，即可獲得 小歪比哇嗚 戰鬥寵物！{% endif %}
