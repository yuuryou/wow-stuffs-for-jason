巨龍時代 · 德魯伊水棲外觀 · 真香手冊第131集

🎯 快速摘要

地圖 瓦德拉肯
NPC 陸佳 (Lu Jia)
NPC座標 /way 52.6 53.8
釣魚訓練師 /way 35.0 48.6 (Sabu)
獲取方式 釣魚 + 隨機團隊副本
所需物品 魚竿、釣魚技能
需收集物品 沉睡月魚 x10 + 覺醒旭魚 x10
獎勵 酣夢鯢鯛 🐠

⚙️ 前置準備

  1. 學習釣魚技能
    前往瓦德拉肯，找釣魚訓練師 Sabu 學習巨龍群島釣魚。
    /way 35.0 48.6 (Sabu - 釣魚訓練師)
  2. 找到 NPC 陸佳
    回到瓦德拉肯主城，找到隨機團隊 NPC 陸佳。
    /way 52.6 53.8

🌟 第一階段 — 沉睡月魚 x10

  1. 進入團本
    與陸佳對話，選擇倒數第 4 個選項 「化身魚波」進入團隊副本。
  2. 釣取沉睡月魚
    進入後直走到正前方水池，使用釣魚技能釣取 10 條沉睡月魚。
  3. 離開副本
    點擊左上角人物頭像 → 離開副本。

🔥 第二階段 — 覺醒旭魚 x10

  1. 進入第二個團本
    再次與陸佳對話，選擇倒數第 3 個選項 「融火侵攻」進入團隊副本。
  2. 前往岩漿處
    等 NPC 說完話左邊大門打開，忽略路上小怪，直走到 BOSS 面前的圓環岩漿處。
  3. 釣取覺醒旭魚
    在岩漿處使用釣魚技能釣取 10 條覺醒旭魚。
  4. 離開副本
    點擊人物頭像離開副本。

🎉 第三階段 — 解鎖外觀

  1. 重返第一個團本
    再次與陸佳對話 → 「化身魚波」 → 回到第一個團本。
  2. 扔魚入池
    走到水池邊，將 20 條魚（10條沉睡月魚 + 10條覺醒旭魚）全部扔進水池。
  3. 獲得 Buff
    右上角獲得 「通感錘釣客」 Buff（持續 3 分鐘）。
  4. 釣上奇娜
    在水池使用釣魚，釣上 「奇娜」（靈魂綁定物品）。
  5. 解鎖外觀
    在背包中右鍵使用「奇娜」→ 外觀解鎖！

✂️ 更換外觀

  1. 前往理髮店
    前往任意主城的理髮店（如瓦德拉肯）。
  2. 選擇水棲形態
    導航至水棲形態 → 選擇 「酣夢鯢鯛」。

💡 小提示

  • 任何形態都可以釣魚，不需要切回人形。
  • 通感錘釣客 Buff 僅持續 3 分鐘，扔完魚後要立刻開始釣。
  • 若失敗，只需離開副本重新進入即可重試。
  • 此任務無釣魚技能等級限制，任何等級均可完成。
  • 此為德魯伊專屬外觀解鎖。
