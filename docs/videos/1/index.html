1. 尖刺半殼

類型: 背部（披風）

獲取: 地面拾取

位置: 文諾拉克斯殘骸

座標:

物件: 尖刺貝殼

從晦暗大本營向南前往文諾拉克斯殘骸區。在殘骸左側的大型動物骸骨下方找到閃亮的尖刺貝殼物件，點擊拾取即可。

2. 索爾提亞牧人握柄

類型: 拳套

獲取: 擊殺拾取

位置: 奈格塔爾全境巨型蘑菇頂部

NPC: 蠕動軟體怪

使用彈跳蘑菇、氣孢或抓鉤攀爬至巨型蘑菇頂部。擊殺上面的蠕動軟體怪有機會掉落拳套幻化。

影片作者阿落只給了座標但沒提到在蘑菇頂上。NGA 多位玩家表示在地上找了好久才發現要在蘑菇上。

3–6. 古代地穴聖物箱

類型: 寶箱（內含 4+ 把武器）

位置: 維爾拉頓地穴

座標:

物件: 古代地穴聖物箱

進入維爾拉頓地穴，仔細探索所有分支通道。寶箱不會顯示在小地圖上，必須肉眼搜尋最深處的每個角落。

內含:

#物品類型
3艾隆納斯防衛者之劍單手劍
4被遺忘的維爾拉頓之劍單手劍
5塔爾維洛水晶匠之錘單手錘
6塔爾維洛祝福之刃單手劍

寶箱可能還會掉落其他德萊尼風格武器。
